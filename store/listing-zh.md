# 商店页面资料（公开版）

提交到 addons.mozilla.org 时按下面各栏填写。标了“待你决定”的需要你自己定。

## 名称

已打开作品批量下载器 for Pixiv

## 简介（≤ 250 字）

一键下载浏览器里所有已打开的 Pixiv 作品页原图。可按标签自动分文件夹，把标签、作者和作品链接写入图片属性，按分辨率跳过小图，动图可保存为 GIF、无损 APNG 或原始帧。非 Pixiv 官方扩展。

## 详细说明

先在浏览器里打开想保存的 Pixiv 作品页（形如 pixiv.net/artworks/数字），然后点工具栏按钮，一次把这些作品的原图全部下载下来。多页作品会保存每一页。

**主要功能**

- **批量下载已打开的作品**：扫描所有窗口的标签页，自动去重，下载原图。
- **按标签分文件夹**：在规则页设置“标签 → 文件夹”，例如把带“原神”或“Genshin Impact”标签的作品存到 `Pixiv/原神/`。规则按顺序匹配，同时比对原始标签和 Pixiv 提供的译名。弹窗里点一下标签就能新建规则。
- **写入图片属性**：把标签、作者名和作品链接写入 JPG / PNG 的 XMP 元数据。Windows 资源管理器“属性 → 详细信息”里显示为“标记 / 作者 / 备注”，可以按标记搜索。
- **尺寸筛选**：静态图片和动图分别设置，可按“长边和短边都达到”或“总像素数达到”跳过小图。
- **动图（ugoira）**：可存为 GIF（为每个动图生成专属调色板）、APNG（无损全彩色）或原始帧压缩包（附带帧时长等信息），可多选。
- **可靠下载**：网络错误和限流会自动重试；保存前检查文件完整性，不会把错误页或半张图存下来；失败的项可以一键重试。
- **进度不丢失**：弹窗关掉后下载仍在后台进行，再次打开时顶部显示进度或上次结果；工具栏图标上也显示进度。
- **中英文界面**：默认跟随浏览器语言，也可以在弹窗和规则页右上角手动切换。

**说明**

- 需要在浏览器里登录 Pixiv，扩展用你当前的登录状态访问作品信息，和你自己打开网页时一样。
- 文件保存在 Firefox 默认下载目录里，默认放进 `Pixiv` 文件夹，可以在弹窗里改成别的文件夹（可多级）或直接存在下载目录。要换到其他磁盘，请在 Firefox 设置里修改默认下载目录。
- 扩展只和 pixiv.net、pximg.net 通信，不收集、不上传任何数据。标签规则等设置只保存在你自己的浏览器里，可以在规则页导出备份。
- 本扩展不是 Pixiv 官方产品。

## 截图建议（可选，按顺序）

1. 弹窗：作品列表，显示每个作品的标签和保存位置
2. 规则页：几条“标签 → 文件夹”规则
3. 弹窗顶部的下载结果卡片（有进度条和统计）
4. Windows 资源管理器里一张图片的“属性 → 详细信息”，能看到标记和作者

截图里如果出现别人的作品缩略图或标题，注意版权，可以用自己的作品或打码。
